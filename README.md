# 🎨 Projeto Bootstrap

Este projeto foi desenvolvido como parte dos estudos de **desenvolvimento web responsivo**, utilizando o framework **Bootstrap** para estilização e estrutura de layout.

## 🛠️ Tecnologias utilizadas

- HTML5
- Bootstrap 4/5 (presumido)
- CSS (complementar, se necessário)

## 📁 Estrutura do projeto

- `index.html`: página principal com estrutura básica
- `siteCompleto.html`: versão mais completa do site com componentes adicionais
- `img/`: pasta com imagens utilizadas no projeto

## 📌 Funcionalidades

- Layout responsivo com grid do Bootstrap
- Componentes visuais como cards, botões e navbar
- Estilização moderna e adaptável a diferentes dispositivos
